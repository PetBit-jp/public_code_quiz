# PetBit 問題集

## 構成

```
algorithm/   アルゴリズム問題
coding/      コーディング・設計問題
```

各問題は **Java / Python / TypeScript** の 3 言語で用意しています。好きな言語を 1 つ選んで解いてください。

| 言語 | 必要なバージョン | 実行例 |
|---|---|---|
| Java | 17 以上 | `java RestDetection.java` |
| Python | 3.9 以上 | `python3 rest_detection.py` |
| TypeScript | Node.js 22.18 以上 | `node rest_detection.ts` |

外部ライブラリは使っていないので、インストールは不要です。
