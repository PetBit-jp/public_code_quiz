中身は同じものを 3 言語で用意しているので、好きな言語を 1 つ選んでください。

> 「毎日ちゃんと散歩しているのに、連続記録の日数がおかしい気がします」

## 仕様

関数名は言語に合わせて表記が変わります（Python では `daily_totals` / `current_streak`）。

### `dailyTotals(records)`

首輪から届いた記録（5分ごとの歩数）を、**日本時間（JST）の日付ごと** に合計して返します。

- 記録は届いた順に並んでおり、**時刻順とは限らない**
- 通信が切れると、復帰後にまとめて再送される。**同じ `timestamp` の記録は再送なので 1 回だけ数える**
- 歩数が負の記録はセンサーエラーなので無視する
- 記録が 1 件も無い日は結果に含めない

### `currentStreak(totals, goal, today)`

**昨日から遡って**、目標歩数 **以上** を何日連続で達成しているかを返します。

- 今日はまだ終わっていないので数えない
- 記録が 1 件も無い日は 0 歩として扱う
