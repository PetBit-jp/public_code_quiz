## チケット

> 散歩が足りていない子の飼い主さんに、プッシュ通知で教えてあげたい（CS チームより）

CS とのやり取りで決まった仕様です。

- 毎週 **月曜の朝** にバッチで実行し、**先週（月〜日）** の散歩が少なかった犬の飼い主にプッシュ通知を送る
- 散歩不足とは、先週の **1日あたり平均歩数** が、サイズ別の目安の **6割未満** であること

  | サイズ | 目安（歩/日） |
  |---|---|
  | 小型 `small` | 5,000 |
  | 中型 `medium` | 8,000 |
  | 大型 `large` | 10,000 |

- 首輪の記録が無い日（外していた日・充電切れの日）は平均から除く。記録がある日が **4日未満** の週は判定しない
- 対象は **犬のみ**。アプリで「持病あり」にチェックがある子は除く
- バッチが再実行されても、**同じ子** に同じ週に 2 回送らない
- 文言（CS 作成）:「{名前}ちゃん、先週は少しお散歩が少なめでした。今週は少し長めのお散歩はいかがですか？」

### CS とのやり取り（抜粋）

```
開発: 「足りていない」の基準はどうしますか
CS  : 獣医さん監修の目安表があります。小型 5000、中型 8000、大型 10000 歩/日。その 6 割未満なら不足で
開発: どの期間で見ますか
CS  : 先週の月〜日で。月曜の朝に届くようにしたいです
開発: 首輪を外していた日は？
CS  : その日は平均から外してください。記録がある日が 4 日もない週は、判定しないでほしいです
開発: 猫はどうしますか
CS  : 今回は犬だけで
開発: 持病のある子は？
CS  : アプリの「持病あり」にチェックがある子は外してください
開発: 多頭飼いの方はどうしますか
CS  : うーん、ちょっと考えておきます
```
