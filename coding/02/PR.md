# feat: 散歩リマインダー通知を追加

## 概要

先週の散歩が少なかった犬の飼い主へ、毎週月曜にプッシュ通知を送る機能を実装しました。

## 変更内容

- `WalkShortageRule`: 散歩不足を判定するルールを追加
  - 直近7日間の1日あたり平均歩数を、犬のサイズ別の目安と比較
  - 記録が無い日は除外して平均を計算
  - 記録が4日未満の場合は判定をスキップ
  - 猫・持病ありの子は対象外
- `NotificationPipeline`: 登録されたルールを評価して通知を送るパイプラインを追加
  - 同じ飼い主への、同じ週の重複送信を防止
- `NotificationChannel` / `ChannelFactory`: 通知チャネルを抽象化
  - 現在はプッシュ通知のみ対応。メール・SMS にも将来拡張できる設計にしています
- `RuleRegistry`: 通知ルールをプラグインのように追加できる仕組みを導入

## 設計のポイント

- **拡張性**: 新しい通知ルールは `NotificationRule` を継承して登録するだけで追加できます
- **疎結合**: 判定ロジックと送信処理を分離し、チャネルの差し替えが容易です
- **可読性**: 判定処理を Step ごとに分けてコメントを付けています
