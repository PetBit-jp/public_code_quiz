# 健康アラート

[`LegacyAlertService.java`](LegacyAlertService.java) は「ペットの健康アラートを判定する日次バッチ」です。

現在のアラートは4種類です。

| type | 条件 |
|---|---|
| `low_activity` | 当日の合計歩数が、過去7日平均の50%未満 |
| `low_battery` | バッテリー残量が15%未満 |
| `no_data` | 最終受信から24時間以上経過 |
| `restless_night` | 0〜4時の歩数合計が200を超えている |

なお `no_data` が出ているときは、`low_activity` と `restless_night` は**出さない**仕様です（データが無いだけなので）。

## 1st

このコードの問題点を **できるだけ多く** 挙げてください。

## 2nd

ここで **追加要件** が来たとします。

> アラートを来期までに **20種類に増やします**。
> - 「水飲み回数の減少」「体重の急変」「睡眠の分断」…
> - 種類ごとに **判定に必要なデータが違います**
> - 閾値は **犬種・年齢ごとに変えたい**
> - `no_data` による抑制対象も、種類ごとに違います

どう変更しますか。 クラス図・箇条書き・口頭、伝わる形なら何でも構いません。

## 3rd

2nd で説明した設計を、**アラート2種類ぶんだけ** コードにしてください。

全部を書き切る必要もなく、動かなくても OK です。　

## 実行方法

```sh
java LegacyAlertService.java
```
